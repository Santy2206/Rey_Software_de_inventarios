REY es una aplicación de escritorio (Python + Flet) para gestionar el
inventario de varias bodegas, ventas, clientes y movimientos. Usa una
base de datos local PostgreSQL y puede sincronizar con Supabase.

---------------------------------------------------------------------
 A. REQUISITOS DEL EQUIPO
---------------------------------------------------------------------
  - Windows 10 / 11 de 64 bits
  - 4 GB de RAM (8 GB recomendado), 1 GB libre en disco
  - PostgreSQL 16 o superior
  - Pantalla de 1366 x 768 o mayor

---------------------------------------------------------------------
 B. INSTALACIÓN EN WINDOWS (ejecutable)
---------------------------------------------------------------------
 1. Descargue el archivo REY_Inventarios_v2.0_Windows.zip desde la
    carpeta compartida de Google Drive y descomprímalo.

 2. Instale PostgreSQL (si no lo tiene):
      https://www.postgresql.org/download/windows/
    Durante la instalación anote la contraseña del usuario "postgres"
    y deje el puerto 5432.

 3. Doble clic en  crear_base_datos.bat
    Escriba la contraseña de "postgres" cuando la pida. El script crea
    el usuario rey_user, la base de datos rey_inventarios, las tablas y
    los datos de prueba.

 4. Doble clic en  instalar_rey.bat
    Copia la aplicación a  %LOCALAPPDATA%\Programs\REY Inventarios
    y crea el acceso directo "REY Inventarios" en el Escritorio.

 5. Abra "REY Inventarios" desde el Escritorio e ingrese con:
       Usuario: admin      Contraseña: admin123   (administrador)
       Usuario: empleado   Contraseña: empleado123 (empleado)

 (Opcional) Para sincronizar con la nube, edite el archivo .env de la
 carpeta de instalación y coloque SUPABASE_URL y SUPABASE_KEY reales.

---------------------------------------------------------------------
 C. EJECUTAR DESDE EL CÓDIGO FUENTE (desarrolladores)
---------------------------------------------------------------------
   git clone https://github.com/Santy2206/Rey_Software_de_inventarios.git
   cd Rey_Software_de_inventarios
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   (crear el archivo .env, ver deploy\windows\env.ejemplo)
   python main.py          -> modo escritorio
   python main.py --web    -> modo navegador  http://localhost:8550

 Generar el ejecutable:  doble clic en deploy\windows\construir_ejecutable.bat

---------------------------------------------------------------------
 D. SOLUCIÓN DE PROBLEMAS
---------------------------------------------------------------------
 - "Faltan las credenciales de la base de datos": falta el archivo .env
   junto al ejecutable. Copie env.ejemplo como .env.
 - "connection refused" al iniciar: el servicio de PostgreSQL no está
   activo. Inícielo en Servicios de Windows (postgresql-x64-16).
 - Windows SmartScreen bloquea el .exe: clic en "Más información" y
   luego en "Ejecutar de todas formas" (el ejecutable no está firmado).
